My Projects

Final Year Internship (PFE) · UCCS

Predicting Material Synthesizability with LLMs & Graph Neural Networks

Built an end-to-end AI pipeline to filter AI-generated candidate crystal structures by synthesizability, reducing costly DFT calculations. Fine-tuned Llama-3.1-8B, Qwen2-7B and Gemma-2-9B with LoRA on ~100k structures, compared four GNNs (ALIGNN, CHGNet, M3GNet, MEGNet), and designed an LLM–GNN fusion model reaching 96.96% accuracy and 0.997 ROC-AUC. Extended the approach to chemical explanation generation and precursor prediction, with experiments run on a GPU cluster (SLURM).

Python PyTorch Hugging Face LoRA / PEFT LLMs GNNs SLURM
